# Affise Attribution Module Meta

Flutter wrapper package for the Affise Meta native module.

This package does not expose a Dart API. Add it to a Flutter application to include the native Meta module dependency for Android.

## Integration

### Integrate as dependency

Run console command

```console
flutter pub add affise_attribution_lib
flutter pub add affise_attribution_module_meta
```

or add dependency to `pubspec.yaml` in your flutter application

```yaml
dependencies:
  affise_attribution_lib: ^1.7.15
  affise_attribution_module_meta: ^1.7.15
```

## Native Dependencies

Android:

```kotlin
com.affise:module-meta:1.7.15
```

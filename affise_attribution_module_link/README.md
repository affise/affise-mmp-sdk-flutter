# Affise Attribution Module Link

Flutter wrapper package for the Affise Link native module.

This package does not expose a Dart API. Add it to a Flutter application to include the native Link module dependency for Android and iOS.

## Integration

### Integrate as dependency

Run console command

```console
flutter pub add affise_attribution_lib
flutter pub add affise_attribution_module_link
```

or add dependency to `pubspec.yaml` in your flutter application

```yaml
dependencies:
  affise_attribution_lib: ^1.7.15
  affise_attribution_module_link: ^1.7.15
```

## Native Dependencies

Android:

```kotlin
com.affise:module-link:1.7.15
```

iOS:

```ruby
AffiseModule/Link 1.7.15
```

Swift Package Manager:

```swift
AffiseModuleLink 1.7.15
```

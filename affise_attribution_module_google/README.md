# Affise Attribution Module Google

Flutter wrapper package for the Affise Google native module.

This package does not expose a Dart API. Add it to a Flutter application to include the native Google module dependency for iOS.

## Integration

### Integrate as dependency

Run console command

```console
flutter pub add affise_attribution_lib
flutter pub add affise_attribution_module_google
```

or add dependency to `pubspec.yaml` in your flutter application

```yaml
dependencies:
  affise_attribution_lib: ^1.7.15
  affise_attribution_module_google: ^1.7.15
```

## Native Dependencies

iOS:

```ruby
AffiseModule/Google 1.7.15
```

Swift Package Manager:

```swift
AffiseModuleGoogle 1.7.15
```

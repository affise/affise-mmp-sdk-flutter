# Affise Attribution Module Persistent

Flutter wrapper package for the Affise Persistent native module.

This package does not expose a Dart API. Add it to a Flutter application to include the native Persistent module dependency for iOS.

## Integration

### Integrate as dependency

Run console command

```console
flutter pub add affise_attribution_lib
flutter pub add affise_attribution_module_persistent
```

or add dependency to `pubspec.yaml` in your flutter application

```yaml
dependencies:
  affise_attribution_lib: ^1.7.15
  affise_attribution_module_persistent: ^1.7.15
```

## Native Dependencies

iOS:

```ruby
AffiseModule/Persistent 1.7.15
```

Swift Package Manager:

```swift
AffiseModulePersistent 1.7.15
```

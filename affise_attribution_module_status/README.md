# Affise Attribution Module Status

Flutter wrapper package for the Affise Status native module.

This package does not expose a Dart API. Add it to a Flutter application to include the native Status module dependency for Android and iOS.

## Integration

### Integrate as dependency

Run console command

```console
flutter pub add affise_attribution_lib
flutter pub add affise_attribution_module_status
```

or add dependency to `pubspec.yaml` in your flutter application

```yaml
dependencies:
  affise_attribution_lib: ^1.7.15
  affise_attribution_module_status: ^1.7.15
```

## Native Dependencies

Android:

```kotlin
com.affise:module-status:1.7.15
```

iOS:

```ruby
AffiseModule/Status 1.7.15
```

Swift Package Manager:

```swift
AffiseModuleStatus 1.7.15
```
